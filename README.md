## Projet abandonné (Lisez README)

Ce projet d'application est realisé sur Godot.
UhaNC est une application qui permet d'exploiter une base de données stockant des données sur des chevaux dans Minecraft.
Ce projet ne peut pas être éxecuté en local a cause de son instabilité.

## Fonctionnalités:
- Insertion/Modfication/Suppression de données dans la base
- Visualisation des données
  
## Informations supplémentaires:
- Le projet a été abandonné pour être réécrit sur un site web en HIML/CSS/JavaScript (avec Astro), projet [UmaMC V2]()
