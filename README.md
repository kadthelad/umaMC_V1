## Projet abandonné (Lisez README)

Ce projet d'application est realisé sur Godot.
UhaNC est une application qui permet d'exploiter une base de données stockant des données sur des chevaux dans Minecraft.
Ce projet ne peut pas être éxecuté en local a cause de son instabilité.

## Fonctionnalités:
- Insertion/Modfication/Suppression de données dans la base
- Visualisation des données
  
## Informations supplémentaires:
- Le projet a été abandonné pour être réécrit sur un site web en HIML/CSS/JavaScript (avec Astro), projet [UmaMC V2](https://github.com/kadthelad/umaMC_V2)

### Instructions pour utiliser l'application:
- Avoir une base de données valide ([Google Drive](https://drive.google.com/file/d/1O4X0zX_6CxppIRRxitQITINSMyOi0zcD/view?usp=sharing))
- Écrire le chemin (absolu) de la base de données dans le champ de texte en haut de l'écran
- Appuyer sur le bouton juste à droite
- Explorer la base de données!
